### **Tool Definition Improvements**

- Add **better error handling** around JSON parsing — especially for malformed outputs from Planner.

### **Fallback Strategies**
- Implement **fallbacks** for the **Planner** in case of incomplete or invalid outputs (e.g., retry with a refined prompt).
- For the **Reviewer**, introduce a fallback to flag incomplete or empty node configurations (e.g., empty `body` in the `response_builder`).

- Ensure **context is preserved** across agents, especially from Planner to Builder — include validation of node types and configuration.
- Pass **error logs** between agents to allow contextual retries or corrections (e.g., Builder should inform Planner when a node could not be created).

### **Model Compatibility**
- Test the model used by the **Builder** for **tool calling support** and consider switching to a more reliable model if fallback is frequent.
- Consider **fine-tuning or using a specialized model** for JSON output formatting to reduce malformed outputs.
