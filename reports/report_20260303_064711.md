## 3. Multi-Agent System Improvements

### Builder Agent
- **Add robust error-handling and logging for failed tool calls.** This includes logging the raw LLM response that failed the tool call.
- **Improve prompt engineering for tool calling.** The prompt should emphasize strict JSON formatting and tool call structure to reduce fallback usage.

### Planner Agent
- **Add validation before final output.** The system should check for complete JSON structure and raise a warning if raw output is cut off.
- **Prompt engineering:** Add a note that encourages completion of the full JSON output.

### Reviewer Agent
- **Add contextual feedback.** The Reviewer could be improved to include suggestions for optimization or best practices, even if no issues exist.
- **Pass additional context to the Reviewer:** Include the original functional requirements to enable richer feedback.

### Inter-Agent Communication
- **Pass raw Planner output to the Reviewer.** The Reviewer can then analyze the raw plan for consistency and completeness, not just the final parsed version.
- **Add a shared context store.** This would allow agents to track state like fallback usage, validation issues, or retries across the system.

### Prompt Engineering
- **Add explicit formatting instructions in agent prompts.** For example, “Use only JSON. No markdown. No icode blocks. No partial JSON. Output must be complete and valid.”
